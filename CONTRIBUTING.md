# Contribuir a Eleuthera Cinema Suite Profesional

Gracias por ayudar a mejorar el proyecto.

## Antes de enviar código

1. Crea o revisa un Issue relacionado con el cambio.
2. Trabaja en una rama separada.
3. Mantén el cambio limitado al problema que intentas resolver.
4. No modifiques módulos que funcionan si el cambio no los necesita.
5. Ejecuta las verificaciones y pruebas relacionadas con el área modificada.
6. No incluyas secretos, claves privadas, licencias emitidas ni datos personales.

## Pull Requests

Incluye:

- Qué problema resuelve.
- Qué archivos o módulos cambia.
- Cómo fue probado.
- Riesgos o limitaciones conocidas.
- Capturas solo cuando el cambio sea visual.

Evita mezclar refactors masivos con correcciones funcionales en el mismo PR.

## Reportar bugs

Incluye sistema operativo, versión de Python, pasos exactos para reproducir, resultado esperado, resultado real y cualquier traceback relevante.


## Condición no comercial

Toda contribución aceptada pasa a formar parte de un proyecto estrictamente sin fines de lucro y se distribuye bajo la licencia no comercial incluida en `LICENSE`. No se aceptarán cambios destinados a introducir venta de licencias, publicidad, suscripciones, paywalls, compras dentro de la aplicación ni otros mecanismos de monetización.
